# Localization glossary

The terms the interface uses, in the eight languages it ships in. Use the term of a row
everywhere that concept appears, in every language, so that Piccolo reads the same from one
screen to the next. A new string that needs a term not listed here adds the row first.

The terms follow the names macOS uses for the same things in each language (Settings,
Accessibility, Login Items, Displays, Restart, Quit, ...). The notes at the end list the terms
that have not yet been checked against the macOS UI of their language. Check the system's own
menus in a language before changing a term that the system also shows.

Keep the keyboard symbols (⌃ ⌥ ⇧ ⌘) and the name "Piccolo" as they are in every language.

## Notes

- Keypad key names (Keypad, Enter, Help, Clear) stay in English in zh-Hans, and in zh-Hant
  for Enter, Help and Clear.
- Japanese: 設定 is Settings; the config file is always 設定ファイル, so the two never mix.
- French and Spanish: the adjectives agree with their nouns. fenêtre, Accessibilité and
  animation are feminine (autorisée, désactivée, lente; concedida, desactivada, lenta).
- Terms written from memory, not yet checked against the macOS UI of that language: Login
  Items and Launch at login in fr, es, pt-BR and de, and Display in de and pt-BR. Check them in
  System Settings before changing the strings that use them.
- Plural forms: French, Spanish, Brazilian Portuguese and German need `one` and `other`;
  Japanese and both Chinese languages have only `other`. `CatalogTests` checks this.
